# OverTheWire Bandit – Writeups

This repository contains my notes and writeups for the **OverTheWire Bandit Wargame**, covering **Level 0 to Level 15**.

The writeups focus on understanding Linux commands, file permissions, SSH, networking, encoding, compression, and basic cybersecurity concepts through hands-on challenges.

### Topics Covered

* Linux command-line basics
* SSH and authentication
* File and directory manipulation
* `grep`, `find`, `sort`, `uniq`, `strings`, `tr`, etc.
* Base64 and ROT13 encoding
* Hexdumps and file identification
* Gzip, Bzip2 and Tar
* SSH private keys
* Netcat and network ports
* SSL/TLS connections

The goal of this repository is to document my **learning process and practical cybersecurity experience** while solving the Bandit challenges.
